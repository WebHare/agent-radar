# Contributing to Agent Radar

Thanks for your interest in Agent Radar!

## Issues

Anyone is free to [file an issue](../../issues): bug reports, questions and ideas are all welcome. For a bug,
please say which macOS version you use, where the conversation runs (VS Code extension, VS Code's integrated
terminal or which terminal app), and what you expected to see.

## Code contributions

We can only accept code contributions under a Contributor License Agreement (CLA). We need it to be able to
publish updates of the app, including in the App Store, under our own name.

So if you'd like to contribute code, please contact us first, by opening an issue that describes what you
want to change, **before** you start working on it. We'll then discuss the change and the CLA with you. We
can't accept pull requests that weren't agreed on beforehand.

See [DEVELOPERS.md](DEVELOPERS.md) for how the app works and how to build and test it.
